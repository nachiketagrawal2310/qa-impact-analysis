# Mobile Checklist

Apply when repository evidence or the requirement indicates Android/iOS impact.

Android search patterns:
- Kotlin/Java
- Retrofit/Ktor/OkHttp/Apollo
- repositories/services
- data classes/models
- ViewModel/screen usage

iOS search patterns:
- Swift
- URLSession/Alamofire/Apollo
- Codable models
- repositories/services
- SwiftUI/UIKit screens

Consider backward compatibility for deployed mobile versions when a shared backend contract changes.
